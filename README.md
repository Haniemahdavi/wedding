# کارت دعوت دیجیتال عروسی

## فایل‌ها
| فایل | کاربرد |
|---|---|
| `index.html` | خود کارت دعوت (مهمان‌ها این را می‌بینند) |
| `config.js` | **همه‌ی متن‌ها، تاریخ، آدرس و لینک نقشه — فقط این را ویرایش کنید** |
| `links.html` | صفحه‌ی ساخت لینک شخصی از روی اکسل |
| `guests-template.xlsx` | نمونه‌ی فایل اکسل مهمان‌ها |
| `assets/music.mp3` | آهنگ پس‌زمینه (خودتان اضافه کنید، اختیاری) |

## مرحله ۱ — ویرایش اطلاعات
`config.js` را با یک ویرایشگر متن (Notepad یا VS Code) باز کنید و اسم‌ها، تاریخ، ساعت، آدرس و لینک نقشه را عوض کنید.
- لینک نقشه: در گوگل‌مپ یا نشان یا بلد، روی محل بزنید ← «اشتراک‌گذاری» ← لینک را کپی کنید و جای `url` بگذارید.
- آهنگ: یک فایل mp3 (ترجیحاً زیر ۳ مگابایت) را با نام `music.mp3` در پوشه‌ی `assets` بگذارید. اگر نباشد، دکمه‌ی موزیک خودبه‌خود مخفی می‌شود.
- متن پیش‌نمایش لینک در تلگرام/واتساپ: خطوط `og:title` بالای `index.html`.

## مرحله ۲ — گذاشتن روی گیت‌هاب (رایگان)
1. در github.com ثبت‌نام کنید و وارد شوید.
2. بالا سمت راست ‌**+** ← **New repository**. اسم را مثلاً `wedding` بگذارید، روی **Public** باشد، **Create repository**.
3. در صفحه‌ی ریپو روی لینک **uploading an existing file** بزنید و **همه‌ی محتوای این پوشه** (نه خود پوشه) را بکشید و رها کنید؛ پوشه‌ی `assets` هم باید باشد. پایین **Commit changes**.
4. **Settings** ← از منوی چپ **Pages** ← در قسمت Branch، `main` و `/ (root)` را انتخاب کنید ← **Save**.
5. یکی دو دقیقه صبر کنید. آدرس سایت شما می‌شود:
   `https://USERNAME.github.io/wedding/`

> نکته: گیت‌هاب‌پیجز در ایران معمولاً بدون فیلترشکن باز می‌شود، ولی قبل از ارسال، لینک را روی یک گوشی با اینترنت معمولی امتحان کنید.

## مرحله ۳ — ساخت لینک شخصی هر مهمان
1. `guests-template.xlsx` را باز کنید و مهمان‌ها را وارد کنید:
   ستون A = خط اول روی پاکت (مثلاً «سرکار خانم محمدی»)، ستون B = خط دوم (مثلاً «و خانواده عزیز»)، ستون C = موبایل (اختیاری).
2. آدرس `https://USERNAME.github.io/wedding/links.html` را باز کنید.
3. فایل اکسل را انتخاب کنید ← برای هر نفر لینک ساخته می‌شود.
4. «کپی لینک» یا «کپی پیام» بزنید و برای مهمان بفرستید؛ یا «دانلود اکسل با لینک‌ها» تا همه را یک‌جا داشته باشید.

لیست مهمان‌ها روی گیت‌هاب آپلود **نمی‌شود**؛ اسم هر نفر فقط داخل لینک خودش است. هر وقت مهمان جدید داشتید، فقط دوباره از `links.html` لینک بسازید؛ لازم نیست چیزی را روی گیت‌هاب عوض کنید.

## تغییرات بعدی
هر وقت `config.js` را عوض کردید، در گیت‌هاب روی همان فایل ← آیکون مداد (Edit) ← تغییر ← **Commit changes**. لینک‌هایی که قبلاً فرستاده‌اید همچنان کار می‌کنند.
